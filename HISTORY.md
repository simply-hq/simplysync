# Project history

SimplySync's public history begins on June 5, 2026 with the first consolidated
monorepo snapshot. Earlier prototypes were not preserved as commits.

Before the repository was opened, its development history was reconstructed as
a chronological set of source-tree checkpoints. The reconstruction keeps the
substantive evolution of the protocol, engine, relays, native ports, examples,
documentation, security hardening, and cross-platform test suite. Merge-only
commits, repeated generated baselines, internal planning artifacts, and private
operational metadata were intentionally omitted.

Each checkpoint represents the integrated source tree at that stage after the
same publication sanitization. The current `main` tree is the canonical source
for released SimplySync code.
